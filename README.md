# Python Task 05 – HackerRank Coding Practice

This folder contains 20 separate Python solutions for the assigned HackerRank problems.

## Files
- `problem1.py` through `problem20.py`

Each Python file includes the problem name and HackerRank link in comments at the top.

## How to use
1. Open each file and copy its code into the matching HackerRank challenge.
2. Test against the sample input and submit on HackerRank.
3. Upload this `Task_5` folder to `Python_Tasks/Task_5/` in your `Internship_Tasks` GitHub repository.
4. Submit `Task_5.zip` to the LMS.

Please test each solution on HackerRank before final submission.
